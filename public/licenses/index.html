  • Lucide: ISC — ライセンス
  • Transformers.js 4.3.1: Apache-2.0 — ライセンス / ソース
  • ONNX Runtime: MIT — ライセンス / ソース
  • @ffmpeg/ffmpeg 0.12.15: MIT — ライセンス
  • @ffmpeg/core 0.12.10: GPL-2.0-or-later — GPL v2 / リリースに対応するソースとビルド手順 / ソースアーカイブ。配布するcoreは変更していません。FFmpeg n5.1.4と各依存ライブラリの取得元・バージョンは同ソースのDockerfileに記載されています。FFmpegソース
  • Whisperモデル: Tiny / Base / Small。モデルはアプリに同梱せず、ユーザー操作時に提供元から取得します。
